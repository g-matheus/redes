Script

apache2.sh

Comandos e parâmetros

Linhas comuns do Bash

#!/bin/bash é o shebang e seleciona o interpretador Bash. set -Eeuo pipefail faz o script falhar de forma mais segura: -e encerra diante de falhas (com exceções previstas pelo Bash), -E estende uma eventual trap ERR a funções e subshells (shells filhos; trap é uma ação definida para ocorrer diante de um evento; este script não define essa trap), -u acusa variáveis não definidas e pipefail propaga falhas de qualquer comando em uma sequência ligada por |. export DEBIAN_FRONTEND=noninteractive envia ao APT a configuração para evitar perguntas interativas durante instalações. “Shell” é o interpretador de comandos; APT é o instalador de pacotes do Ubuntu.

echo

Imprime mensagens de status no terminal. Sem argumentos, imprime uma linha em branco; não instala nem configura nada.

source "$(dirname "$0")/setup.conf"

source executa o arquivo no shell atual para carregar suas variáveis. $0 é o caminho usado para chamar o script; dirname extrai a pasta desse caminho; $(...) substitui o comando pelo resultado. A barra / junta a pasta ao nome do arquivo. Assim, setup.conf pode estar junto do script mesmo quando ele é chamado de outra pasta.

apt-get install -y apache2

apt-get é o instalador de pacotes do Ubuntu; install solicita a instalação do pacote apache2, o servidor web Apache; -y responde “sim” às confirmações. Um pacote é uma unidade distribuída pelo repositório com programa e arquivos relacionados.

tee ... > /dev/null <<EOF

tee recebe texto pela entrada padrão e o grava no arquivo indicado. > /dev/null redireciona a saída do próprio tee para /dev/null, o destino especial que descarta dados, evitando duplicar o texto no terminal. <<EOF inicia um heredoc e a linha isolada EOF o encerra. Como EOF não está entre aspas, o Bash expande variáveis como $DOMAIN_NAME dentro do bloco. ServerName define o nome principal usado pelo Apache; o arquivo é criado na pasta de configurações disponíveis.

a2enconf, a2ensite, systemctl reload e UFW

a2enconf habilita uma configuração global do Apache; a2ensite habilita um arquivo de site (VirtualHost). “Habilitar” cria a ligação em conf-enabled ou sites-enabled para o arquivo correspondente em *-available. systemctl reload apache2 pede ao serviço Apache já em execução para reler as configurações, sem reiniciar o sistema. ufw allow in "Apache Full" cria uma regra UFW de entrada baseada no perfil Apache Full, que libera HTTP (porta 80) e HTTPS (porta 443); allow permite, in indica tráfego que chega e ufw é o firewall explicado na página Servidor. O script configura um VirtualHost para o domínio e dois para os subdomínios.

a2dissite, rm -f e rm -rf

a2dissite desabilita os VirtualHosts padrão do Apache. rm remove arquivos; -f (“force”) não pede confirmação e ignora arquivos inexistentes; -r (“recursive”) percorre diretórios e seu conteúdo. Por isso rm -rf /var/www/html apaga recursivamente o conteúdo do site padrão — não é reversível sem backup. /var/www/html é o document root padrão (“raiz” dos arquivos servidos pelo site).

mkdir -p e diretivas do VirtualHost

mkdir cria diretórios; -p cria também diretórios pais e não falha se o diretório já existir. Um VirtualHost é a configuração de um site atendido pelo Apache. <VirtualHost *:80> seleciona conexões HTTP recebidas em qualquer endereço local (*) na porta 80; </VirtualHost> encerra o bloco. ServerName identifica o nome do site; ServerAlias adiciona outro nome, aqui www; DocumentRoot indica a pasta dos arquivos públicos. ErrorLog e CustomLog definem registros de erros e acessos. ${APACHE_LOG_DIR} é uma variável do Apache para sua pasta de logs; a barra invertida no gerador impede o Bash de expandi-la antes do Apache. combined é o formato detalhado de registro de acesso.

apache2ctl configtest e reboot

apache2ctl é a ferramenta de controle/diagnóstico do Apache; configtest verifica a sintaxe dos arquivos e informa se a configuração pode ser lida, mas não testa DNS nem acesso externo. Se esse comando terminar sem erro, reboot reinicia o sistema operacional inteiro (não apenas o Apache); aguarde a instância iniciar e reconecte por SSH.
