Publicação no subdomínio 2

Baixe um template web gratuito e envie seus arquivos para o segundo subdomínio usando SCP.

1. Baixe e extraia um template

Escolha um template HTML gratuito, por exemplo no Start Bootstrap. Baixe e extraia o arquivo no computador local. Confirme que o index.html está na raiz da pasta extraída e abra um terminal nessa pasta.

2. Envie o template para a home do servidor

Abra o terminal local dentro da pasta extraída do template. Antes de enviar, conecte-se ao servidor com sua chave privada SSH e crie ~/template-subdomain2 dentro da home do usuário ubuntu. Depois, substitua CAMINHO_DA_CHAVE pelo caminho local da chave e IP_DO_SERVIDOR pelo IP público da instância. O computador local precisa ter o cliente OpenSSH (ssh/scp) instalado e disponível no terminal; sem ele, o shell exibirá command not found.

Enviar o template com SCPterminal local
scp -i "CAMINHO_DA_CHAVE" -r ./* ubuntu@IP_DO_SERVIDOR:~/template-subdomain2/

./* inclui itens não ocultos da pasta atual. A opção -i usa a chave privada. O SCP copia o conteúdo da pasta atual para a home do servidor; para incluir arquivos ocultos do template, envie-os separadamente.

Depois do upload, conecte-se ao servidor por SSH usando a mesma chave privada. No terminal remoto, use sudo para copiar o conteúdo de ~/template-subdomain2 para o DocumentRoot do segundo subdomínio. Esse diretório é /var/www/ seguido pelos valores de SUBDOMAIN2 e DOMAIN_NAME, conforme configurado em apache2.sh. A cópia substitui arquivos com o mesmo nome, mas não remove arquivos antigos que não existam no template. O SCP não executa sudo remotamente, por isso os arquivos são enviados primeiro para a home.

3. Defina o proprietário dos arquivos do site

Depois de copiar os arquivos para o DocumentRoot, execute este comando no terminal remoto do servidor. Com a configuração desta atividade (SUBDOMAIN2=template e DOMAIN_NAME=m7.gs), o caminho do site é /var/www/template.m7.gs:

Alterar proprietário do siteterminal remoto
sudo chown -R www-data:www-data /var/www/template.m7.gs

O comando altera quem é o proprietário dos arquivos e diretórios do site:

  • sudo executa o comando com privilégios de administrador, necessários para alterar a propriedade de arquivos em /var/www.
  • chown significa “change owner” e altera o proprietário e, opcionalmente, o grupo de um arquivo ou diretório.
  • -R aplica a alteração recursivamente: além da pasta indicada, inclui todos os arquivos e subpastas dentro dela.
  • www-data:www-data define www-data como proprietário e também como grupo. Esse é o usuário e grupo normalmente usados pelo Apache no Ubuntu.
  • /var/www/template.m7.gs é o caminho da pasta publicada. Se os valores de domínio ou subdomínio em setup.conf forem diferentes, substitua esse caminho pelo DocumentRoot correspondente; não execute o comando mantendo um caminho que não seja o do site.

Assim, os arquivos passam a pertencer ao usuário do servidor web. O comando não altera as permissões de leitura, escrita ou execução; ele altera somente proprietário e grupo.
