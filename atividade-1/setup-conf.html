Atividade 1 • variáveis dos scripts

setup.conf

Domínio e repositório usados pelos scripts. Substitua os exemplos.

Conteúdo gerado

setup.conf
DOMAIN_NAME=m7.gs
SUBDOMAIN1=docs
SUBDOMAIN2=template
SUBDOMAIN1_SITE_REPO_URL="https://github.com/g-matheus/redes1.git"

Variáveis, permissões e DNS

DOMAIN_NAME

É uma variável de configuração Bash: o nome antes de = é a chave e o texto depois é seu valor; não se colocam espaços ao redor de =. Informe o domínio sem http://, https:// ou caminho, por exemplo exemplo.com. Os scripts usam esse valor para nomear o VirtualHost (bloco de configuração de um site no Apache), montar o document root (pasta dos arquivos servidos) e solicitar o certificado TLS.

SUBDOMAIN1 e SUBDOMAIN2

São os rótulos à esquerda do domínio, não incluem o domínio nem pontos. Se o domínio for exemplo.com, valores blog e api formam blog.exemplo.com e api.exemplo.com. Os mesmos nomes são usados nos VirtualHosts e no pedido de certificado.

SUBDOMAIN1_SITE_REPO_URL

Guarda a URL do repositório Git que deploy-subdomain1.sh baixa. Substitua o endereço de exemplo por uma URL real, normalmente terminada em .git. As aspas duplas permitem caracteres como /, : e . no valor sem que sejam interpretados pelo shell. Repositório é o projeto armazenado e gerenciado pelo Git.

DNS, registro A, @ e www

DNS traduz nomes de domínio em endereços de rede. Crie registros para o domínio principal e para cada subdomínio, apontando para o IP público da instância. Um registro A associa um nome a um endereço IPv4; @ costuma representar o domínio raiz no painel DNS; www é um nome adicional que este conjunto de scripts configura como alias do domínio principal. DNS deve estar propagado antes da emissão do certificado.

Permissão 640

chmod configura permissões de arquivo; os dígitos octais representam dono, grupo e outros usuários, nessa ordem. Cada dígito soma leitura (4), escrita (2) e execução (1): 6 = leitura + escrita; 4 = leitura; 0 = nenhum acesso. Portanto, 640 permite ao dono ler e editar, ao grupo ler, e não dá acesso aos demais. A configuração não precisa ser executável: os scripts a carregam com source.

setup.conf e .git

.conf indica um arquivo de configuração lido como comandos de atribuição pelo Bash; este arquivo define variáveis, não executa instalação por si só. Na URL de exemplo, https:// é o protocolo usado para acessar o host GitHub, github.com é o domínio do serviço, as barras separam caminhos e .git identifica o endereço do repositório (não é um arquivo de configuração).
