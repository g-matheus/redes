Atividade 1 • PHP e MySQL

mysql-php.sh

Instala MySQL e PHP para Apache e cria o arquivo de teste do PHP.

Cuidado

phpinfo() expõe detalhes do servidor. Instalação padrão do MySQL, não inclui configurações de segurança.

Script gerado completo

mysql-php.sh
#!/bin/bash

set -Eeuo pipefail
export DEBIAN_FRONTEND=noninteractive

source "$(dirname "$0")/setup.conf"

echo "==> Installing MySQL server..."
echo
apt-get install -y mysql-server

echo "==> Installing PHP..."
echo
apt-get install -y php libapache2-mod-php php-mysql
echo "-> Configuring index.php..."
tee /etc/apache2/mods-enabled/dir.conf > /dev/null << 'EOF'
<IfModule mod_dir.c>
    DirectoryIndex index.php index.html index.cgi index.pl index.xhtml index.htm
</IfModule>
EOF
tee /var/www/$DOMAIN_NAME/index.php > /dev/null << 'EOF'
<?php
phpinfo();
?>
EOF
echo "==> Done! Restarting server..."
reboot

Comandos e parâmetros

Linhas comuns do Bash e echo

#!/bin/bash é o shebang, que seleciona o interpretador Bash. set -Eeuo pipefail interrompe o script em falhas (-e, com exceções do Bash), estende uma eventual trap ERR a funções e subshells (-E; subshell é um shell filho, trap é uma ação definida para ocorrer diante de um evento, e este script não define essa trap), detecta variáveis não definidas (-u) e propaga falhas de qualquer comando em um pipeline (pipefail; pipeline é uma sequência conectada por |). export DEBIAN_FRONTEND=noninteractive passa ao APT, o instalador de pacotes do Ubuntu, a preferência por instalações sem perguntas interativas. echo imprime mensagens; sem texto, apenas cria uma linha em branco.

source "$(dirname "$0")/setup.conf"

source executa o arquivo no shell atual para carregar variáveis. $0 representa o caminho do script; dirname extrai sua pasta e $(...) substitui o comando pelo resultado. Assim o script encontra setup.conf junto de si. DOMAIN_NAME guarda o domínio principal; document root é a pasta de arquivos que o Apache publica para esse domínio.

apt-get install -y mysql-server

apt-get gerencia pacotes do Ubuntu; install solicita instalar o pacote mysql-server, que fornece o serviço de banco de dados MySQL; -y confirma automaticamente as perguntas de instalação. Um banco de dados organiza dados para consulta e atualização.

Pacotes PHP

php instala o interpretador/runtime que executa código PHP; libapache2-mod-php integra esse interpretador ao módulo Apache, para que o servidor processe arquivos PHP; php-mysql fornece ao PHP a extensão necessária para conectar ao MySQL. Apache é o servidor HTTP; PHP é uma linguagem executada no servidor. O sinal -y nas instalações confirma a operação sem perguntar.

tee e heredoc com 'EOF'

tee lê texto da entrada padrão e o grava no caminho indicado. > /dev/null redireciona a saída de tee para o dispositivo especial que descarta dados, para não repetir o conteúdo na tela. << 'EOF' inicia um heredoc, um bloco de texto encerrado pela linha isolada EOF. As aspas no marcador impedem que o Bash expanda variáveis ou execute substituições dentro do bloco. Em /etc/apache2/mods-enabled/dir.conf o texto altera a ordem de arquivos iniciais usada pelo módulo de diretórios do Apache; em /var/www/$DOMAIN_NAME/index.php o Bash expande o domínio no caminho do arquivo criado.

DirectoryIndex

É uma diretiva do módulo mod_dir do Apache. Lista, em ordem de preferência, os nomes que o servidor procura quando o navegador pede uma pasta sem especificar arquivo. Como index.php aparece primeiro, ele é escolhido antes de index.html se ambos existirem. Os nomes restantes são alternativas para outros formatos.

phpinfo()

É uma função PHP que exibe versão, módulos, caminhos e configurações do interpretador e do servidor. O arquivo index.php contém as tags <?php e ?>, que delimitam o código PHP; o ponto e vírgula encerra a instrução. A saída pode revelar informações úteis a um atacante: remova o arquivo de teste depois de conferir a instalação.

reboot

Solicita a reinicialização do sistema operacional da instância (máquina virtual). Os serviços são encerrados e iniciados novamente; a conexão SSH cai. Aguarde a máquina voltar a responder e reconecte antes de executar o próximo script.
